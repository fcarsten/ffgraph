# Frozen pre-retirement Rome graph oracles

Captured from the actual legacy `RomeControl` parser at commit
`5db5a38e9c5c4c5bb176ec08c445ee2ea9b7d248`, now tagged
`ffgraph-pre-legacy-rome-removal`, plus a temporary snapshot-output hook.
The hook was removed after capture. A second independent process produced
byte-identical snapshots before the legacy implementation was deleted.

Capture commands executed before removal:

```sh
cmake --build build/debug --target test_rome_compatibility_pass12 --parallel 2
build/debug/tests/modern_rome/test_rome_compatibility_pass12 \
  --record-legacy-oracles tests/modern_rome/oracles
```

Sixteen snapshots describe all eight accepted fixtures, each with and without
FFGraphicNode/FFGraphicEdge prototypes. Both include the graph Watch and custom
node/edge payload labels used by the regression driver. Graphs start fresh;
merge and duplicate seed collisions have independent per-graph assertions.
Snapshots sort node/edge rows and retain IDs, names, directedness, adjacency,
weights, payloads, geometry, icon/mask/range/shape state and edge routes.
Expected files are never regenerated by the current parser during a test or build.
They complement independent topology/source-graph oracles and historical live
legacy/modern comparisons preserved by the tag and earlier checkpoint reports.
